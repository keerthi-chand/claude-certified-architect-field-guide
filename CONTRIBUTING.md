# Contributing

Corrections and sharper explanations are welcome. Open an issue or a pull request.

## Two rules

**1. No real exam content. Ever.**
Anthropic's exam is covered by a non-disclosure agreement that every candidate accepts before sitting it. Do not submit questions, answer options, or scenarios from the actual exam, paraphrased or otherwise, and do not describe "what was on it." Practice items in this repo are original, written to the style of the twelve samples Anthropic publishes in the official exam guide. A pull request that appears to contain real exam content will be closed without merge.

**2. Judgment over volume.**
This guide is deliberately small. A new item earns its place by teaching a decision the existing material doesn't, not by covering one more fact. If you find a fact that is wrong or has gone stale, fix it; if you want to add a topic, open an issue first and say which task statement in the official guide it serves.

## Style

- Written for someone who will sit the exam. Every section should help them pick the right option under time pressure.
- Prefer a table to a paragraph when the content is a decision.
- Case notes describe real production decisions with identifiers removed. Keep them that way: no company names, no internal system names, no people.
- Practice items follow the official format: a stem, four options, one best answer, and a rationale that says why each wrong option is wrong.

## Verified against

Exam Guide v1.0 (July 2026). If Anthropic publishes a new version, the perishable facts live in `reference/recall-facts.md`; start there.
